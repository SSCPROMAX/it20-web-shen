Über das Projekt

 Ich bin so jemand, der sich jeden Tag eine halbe Stunde den Kopf darüber zerbricht, was er essen soll. Dafür habe ich dieses kleine Tool entwickelt, mit dem man einer Zufallszahl die Wahl überlassen kann – einfach tippen und schon bekommt man ein Tipp! Die gesparte Zeit kann man doch viel sinnvoller nutzen!
